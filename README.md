# Lab-IAEA-ICTP-SMR4246
In this lab activity we will play with different model for image segmentation.



## Model 1: Segnet
reference: Vijay Badrinarayanan, Alex Kendall and Roberto Cipolla "SegNet: A Deep Convolutional Encoder-Decoder Architecture for Image Segmentation." PAMI, 2017.
link to paper: http://arxiv.org/abs/1511.00561

## Model 2: 3D UNet (using the implementation in MONAI lib)
reference: 3D U-Net: Learning Dense Volumetric Segmentation from Sparse Annotation , Çiçek, Ahmed Abdulkadir, Soeren S. Lienkamp, Thomas Brox, Olaf Ronneberger, MICCAI, 2016.
link: https://arxiv.org/abs/1606.06650

The Segnet model will be applied to CAMVID data.

Instead, the MONAI UNET model will be used to perform spleen segmentation.
